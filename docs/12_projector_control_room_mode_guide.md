# 12 — Windows Projector & Control Room Mode Guide

## 1. Design & Human Factors
The Projector / Control Room Mode is engineered specifically for facility managers and control room operators monitoring large screens from across the room (15 to 30+ feet viewing distance).

### Key Features:
- **Massive Distance-Readable LCD Readouts**: 96pt+ font size for water percentage, flow rate, and pump state.
- **Ultra-High Contrast Theme**: Pure deep slate black (`#070a12`) background with neon cyan (`#00e5ff`), emerald (`#10b981`), and danger rose (`#f43f5e`) illuminated annunciators.
- **Full-Screen Kiosk Mode (F11)**: Strips OS title bars, taskbars, and browser chrome for clean permanent wall projection.
- **Automatic Display Wake Lock**: Prevents screen dimming or screensaver activation while pump machinery is operating.
